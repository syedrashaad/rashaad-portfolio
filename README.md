# Rashaad Syed: Intelligent Products

Build a premium, highly polished personal portfolio website for Rashaad Syed.

IMPORTANT:

This is NOT a generic developer portfolio.

This is NOT a cyberpunk AI website.

Do NOT use excessive gradients, glowing neon elements, floating AI brains, neural networks, code rain, glassmorphism everywhere, or generic AI imagery.

The visual benchmark should be the sophistication of an Apple product page:

- extremely clean

- editorial

- spacious

- premium

- minimal

- typography-led

- subtle but exceptional animation

- strong storytelling through scroll

- beautiful micro-interactions

The website should communicate:

Rashaad works at the intersection of

PRODUCT × AI × TECHNOLOGY.

He has a technical foundation in machine learning/software engineering and has progressively moved toward building and leading AI products.

The primary audience is:

- AI Product Managers

- Product Managers

- Technical Product Managers

- AI-native startups

- Product/AI hiring managers

- Technology companies

The objective is to make a recruiter think:

"This person understands the technology deeply, but thinks like a product builder."

==================================================

DESIGN SYSTEM

==================================================

Use a warm off-white / cream background rather than pure white.

Suggested visual direction:

background: #F5F4EF / #F7F6F2

primary text: almost-black #111111

secondary text: muted charcoal/grey

accent: ONE sophisticated dark green or similarly restrained accent

Do not introduce multiple bright colours.

Typography should be a major part of the design.

Use a premium modern sans-serif similar in feeling to:

Inter

Geist

Suisse

Neue Montreal

SF Pro

Use very large headings with tight tracking.

Lots of whitespace.

Maximum content width should feel editorial and intentional.

Rounded corners should be subtle.

Avoid excessive cards.

The site should feel like a technology product launch page rather than a portfolio template.

==================================================

GLOBAL MOTION LANGUAGE

ANIMATION & CREATIVE DEVELOPMENT STACK

==================================================

This portfolio must use advanced web animation and creative-development techniques where they genuinely improve the experience.

Preferred stack:

- Framer Motion / Motion for polished UI transitions and micro-interactions

- GSAP for advanced animation sequences

- GSAP ScrollTrigger for scroll-driven storytelling

- Three.js for selective 3D/WebGL experiences

- React Three Fiber if the project is React/Next.js based

- Drei for useful Three.js abstractions

- Lenis for premium smooth scrolling

- WebGL shaders only for subtle high-end visual effects where appropriate

IMPORTANT:

Do NOT add 3D simply for decoration.

The website should still feel minimal, professional and Apple-like.

Use Three.js/WebGL selectively for 2–3 memorable moments rather than covering the entire website with 3D graphics.

Potential uses:

Create a subtle interactive 3D/WebGL object or abstract spatial composition behind/beside the hero typography.

It should respond gently to:

- cursor position

- scroll position

- device orientation where appropriate

The object should be abstract and sophisticated.

Do NOT use:

- AI brains

- robots

- neural-network globes

- floating code

- generic futuristic holograms

Think Apple product visualization rather than "AI website".

- slow movement

- reveal subtle colour

- nearby logos can react slightly

6. TYPOGRAPHY

Use GSAP SplitText-style animation or an equivalent implementation.

Animate:

- words

- lines

- character masks

- clipping

- opacity

- subtle translation

Do not animate every heading the same way.

7. PAGE TRANSITIONS

If multiple routes/pages exist, use Framer Motion to create elegant page transitions.

The transition should feel like part of one continuous product experience.

8. PERFORMANCE

Three.js/WebGL scenes must:

- lazy load

- use optimized geometry

- minimize texture sizes

- avoid unnecessary post-processing

- pause when outside viewport where possible

- reduce complexity on mobile

- provide a non-WebGL fallback

Maintain excellent Lighthouse performance.

Animation must NEVER make the site difficult to navigate.
